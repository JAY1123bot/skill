# Change Control

`change-control` 是一个为 Codex 设定变更确认流程的 Agent Skill。它让 Codex 在修改项目或外部状态前，先检查并说明计划，等你明确确认后再按批准范围执行。

## 适用场景

当你希望 Codex 先分析、提出方案，再由你决定是否动手时，可以使用这个 Skill。它适用于代码和文档编辑、文件删除或重命名、配置调整、依赖安装，以及提交、推送或发布等外部变更。

例如：

> 使用 change-control，先检查这个项目并告诉我建议修改哪些文件；等我确认后再改。

## 工作流程

1. 确认前只进行理解任务所需的只读检查，并说明拟修改的文件或系统、计划操作及相关影响。
2. 等待你明确回复“确认”或“GO”。
3. 确认后只执行已说明的范围；如果需要扩大范围或增加操作，会再次征求确认。
4. 完成后说明实际改动和验证结果。

## 权限边界

这个 Skill 提供的是行为指引，不能替代 Codex 的沙箱和权限设置，也不能从技术上阻止写操作。需要硬性限制时，请在 Codex 中使用只读权限或相应的审批与沙箱配置。

技能规则见 [`SKILL.md`](SKILL.md)。
